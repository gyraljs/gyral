# Behavior changes in 0.3.1

Gyral 0.3.1 is a patch release, but it changes some 0.3.0 behavior and types. This is a
one-time exception before 1.0's strict versioning: these changes fix defaults that were wrong
or close gaps that 0.3.0 left open, and each has a one-line fix. Testers on a 0.3.1-next.N build
should read this list too, because some items changed between those builds.

Every change is also marked "Behavior change" in its changeset (and so in the package
CHANGELOGs).

## Router (`@gyral/router`)

| Change                                                                                                                                                                                                | Who is affected                                                                          | Fix                                                                                                                             |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `routes()` throws at startup for patterns the two matchers would read differently: `:post-id`, `/v:id`, empty or dot segments, a param named twice, `#`.                                              | Route tables with such patterns.                                                         | Rename params to identifiers (`/:postId`) and drop the odd segments.                                                            |
| Empty segments never match: `/users//1` no longer matches `/users/:id`.                                                                                                                               | Apps that relied on the fallback matcher's leniency.                                     | Redirect to `match(url).path` (ADR 0009 "Canonical paths").                                                                     |
| `RouteMatch` has a required `path` (the canonical URL).                                                                                                                                               | Tests comparing a whole match with `toEqual`; code building matches by hand.             | Add `path`, or compare `name` and `params`.                                                                                     |
| `href()` writes non-ASCII literal segments percent-encoded (`/café` → `/caf%C3%A9`).                                                                                                                  | Snapshot tests of generated links.                                                       | Update the snapshots.                                                                                                           |
| After a push, the browser router scrolls to the `#fragment` target or the top, restores the position on back/forward, and resets focus.                                                               | Apps that manage scroll or focus themselves.                                             | `navigate(url, { scroll: false, focusReset: false })` per call, or `makeRouter({ scroll: false, focusReset: false })`.          |
| A `replace` leaves scroll and focus alone unless asked.                                                                                                                                               | Apps that expected a replace to scroll to the top.                                       | `navigate(url, { replace: true, scroll: true, focusReset: true })`.                                                             |
| Without the Navigation API, the History API path loads on first use, so the first navigation resolves a moment later. If it can't load, navigations become full page loads.                           | Tests that assume a synchronous first navigation in browsers without the Navigation API. | Await `settled()` (or the router's `Routed` message) after navigating.                                                          |
| `setTitle(title)` is removed; `setHead(head)` states the page's whole managed head (ADR 0019). The router input `{ _tag: 'Title' }` is `{ _tag: 'Head', head }` and `RouterSnapshot.title` is `head`. | Apps that call `setTitle`; custom router fakes; tests reading `snapshot().title`.        | `setHead({ title })`, or `setHead(pageHead(…))` with the same function the server passes to `page()`; `snapshot().head?.title`. |

## Core (`@gyral/core`)

| Change                                                                                                                                                                                                                           | Who is affected                                                                                                                                       | Fix                                                                                                                                    |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `define` takes two calls: types first, then the tag and spec (ADR 0023).                                                                                                                                                         | Every component.                                                                                                                                      | `define<State, Msg>(tag, spec)` → `define<State, Msg>()(tag, spec)`; `define(tag, spec)` → `define()(tag, spec)`.                      |
| The intent names are the keys of `intent`, inferred: `IntentName<'…'>` and `Messages<M>` are removed, and the view's `i` offers only names that have a parser.                                                                   | Components that declared `IntentName<…>` in their message union, or whose view names a tag with no parser.                                            | Drop `IntentName<…>` from the union and keep the parsers; type helpers with `Msg` instead of `Messages<Msg>`; add the missing parser.  |
| `intents<Msg>()` is `intentsOf<typeof Component>()`; `IntentNames` takes the names (`IntentNames<'Save'>`), not the union.                                                                                                       | List rows that name intents through a module constant.                                                                                                | `const i = intentsOf<typeof Todos>()`, give the row a return type (`: TemplateResult`), and let the view use its own `i`.              |
| `GyralElementClass` has a fifth type parameter, the intent names (default `string`).                                                                                                                                             | Code that annotates a class with all type parameters.                                                                                                 | Nothing, or pass the names to keep `intentsOf` precise.                                                                                |
| A parser that returns `undefined` synchronously declines: the next element outward with an intent for that event gets it.                                                                                                        | Components with nested intents for the same event, where the outer one must not see what the inner one ignores.                                       | Return a message (or a no-op message) from the inner parser, or check `input.target` in the outer one.                                 |
| `IntentParser<M, P>` is `(input, ctx) => …`.                                                                                                                                                                                     | Code that holds a parser typed `IntentParser<M>` and calls it with one argument.                                                                      | Pass a context, or type the value as `(input: IntentInput) => …`. `form()`, `field()` and `child()` still return one-argument parsers. |
| Any `data-intent-<x>` attribute other than `data-intent-on` is a per-event intent for event `x`.                                                                                                                                 | Markup that used the `data-intent-` prefix for something else.                                                                                        | Rename those attributes.                                                                                                               |
| A `prop.json` prop set to an equal value (same JSON) doesn't re-render or send `PropsChanged`.                                                                                                                                   | Components that counted `PropsChanged` for identical values.                                                                                          | Nothing to do unless you relied on it; compare in `PropsChanged` instead.                                                              |
| `Prop` has a required `equals`.                                                                                                                                                                                                  | Hand-written prop definitions (not the `prop.*` builders).                                                                                            | Add `equals: Object.is`.                                                                                                               |
| `settled()` waits until messages stop arriving (not a fixed 4 turns) and rejects (G0034) for a stream that emits without pause.                                                                                                  | Tests with `await Promise.resolve()` loops before `settled()` (now unneeded); tests that await `settled()` while an endless microtask stream runs.    | Drop the loops; stop or fake the endless stream.                                                                                       |
| `style` attributes the client writes go through the CSSOM and read back serialized (`color: red;`).                                                                                                                              | Tests comparing `getAttribute('style')` strings.                                                                                                      | Compare `el.style.getPropertyValue(…)`, or the serialized form.                                                                        |
| In `html` templates, HTML-only elements inside `<svg>` and bound namespaced attributes (`xlink:href=${v}`) are template errors; whitespace with a newline at the inside edges of `<svg>` is dropped.                             | Templates with those patterns.                                                                                                                        | Use `<foreignObject>` for HTML, `href` for links, an `svg` template for SVG fragments.                                                 |
| Production builds print `Gyral G00NN …` codes instead of message text.                                                                                                                                                           | Code or tests that match production error text.                                                                                                       | Match the code ([errors](errors.md)), or test against a development build.                                                             |
| `gyral/unused-intent` is a warning in `recommended`.                                                                                                                                                                             | Lint runs with `--max-warnings 0`.                                                                                                                    | Remove or rename unused parsers.                                                                                                       |
| `GyralViteConfig` no longer has `resolve` (it was always empty).                                                                                                                                                                 | Code that read `gyralVitePreset().resolve`.                                                                                                           | Drop it.                                                                                                                               |
| Template HTML and `raw()` markup go through a Trusted Types policy named `gyral`.                                                                                                                                                | Pages whose CSP lists allowed policies (`trusted-types …`).                                                                                           | Add `gyral` to the list; without it Gyral falls back to plain strings, which works only while Trusted Types aren't enforced.           |
| Disconnecting stops a host's commands one microtask later; a move (disconnect and connect in one task) keeps them running. A host attached again after a real removal gets the optional `Connected { reconnect: true }` message. | Tests asserting `signal.aborted` (or a subscription's unsubscribe) right after `el.remove()`; components that restarted watches by hand on reconnect. | `el.remove(); await Promise.resolve();` before asserting; re-issue long-lived commands from a `Connected` reducer.                     |

## Server (`@gyral/ssr`)

| Change                                                                                                                                                                      | Who is affected                                                                                       | Fix                                                                                                                     |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `ClientAssets` has a required `css` field.                                                                                                                                  | Code that builds `ClientAssets` by hand.                                                              | Add `css: []`, or the hashed CSS files.                                                                                 |
| Requests other than `GET`/`HEAD` under `/assets/` get 405 from `productionServer` instead of reaching the app.                                                              | Apps that handled other methods under `/assets/`.                                                     | Move those routes elsewhere.                                                                                            |
| `productionServer`'s `fetch` passes its second argument on to the app, and `FetchApp` takes an `Env` type parameter.                                                        | Typed wrappers around `FetchApp`.                                                                     | Add the type argument, or leave the default (`unknown`).                                                                |
| `page({ head })` is renamed `page({ extraHead })`; `PageOptions` extends core's `Head`, and managed head elements (including the description meta) carry `data-gyral-head`. | Every `page()` / `renderPage()` call with `head`; tests matching the description meta's exact markup. | Rename to `extraHead`; move description, canonical, robots, Open Graph meta, alternates and JSON-LD into `Head` fields. |

## Retries and HTTP (`@gyral/core`, `@gyral/http`, `@gyral/testing`)

Retries and CSRF tokens are reached by calling them, so apps that don't use them don't bundle
them ([ADR 0022](../design-docs/0022-http-opt-outs.md)). Every item below is a type error, so
the type checker finds each site.

| Change                                                                                                                                                 | Who is affected                                  | Fix                                                                                                        |
| ------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| `Driver.retry` and `subscription(…, { retry })` are removed; the runtime runs a driver once.                                                           | Drivers and subscriptions with a `retry` policy. | Wrap the driver: `retry(driver, { times, delayMs, backoff })` from `@gyral/core`.                          |
| `makeHttpDriver({ retry })` is removed.                                                                                                                | Apps that gave the http driver a retry policy.   | `retry(makeHttpDriver({ … }), policy)`.                                                                    |
| `HttpRequest.csrf` (`request({ csrf: { meta } })`) is removed.                                                                                         | Requests that read a CSRF token from a `<meta>`. | Configure it once: `makeHttpDriver({ headers: csrfFromMeta('csrf-token') })`, given with `provideDrivers`. |
| `submitForm(url, data, { csrf: { meta } })` is removed; `{ csrf: { token } }` stays.                                                                   | Forms that read a CSRF token from a `<meta>`.    | The same driver setting.                                                                                   |
| The `retry` option of `fakeDriver` (`@gyral/testing`) and `fakeHttp` (`@gyral/http/testing`) is removed.                                               | Tests of retry behavior.                         | `retry(fakeDriver(…), policy)`; keep reading `calls` and `inputs` from the fake itself.                    |
| Development builds warn once when a non-GET request goes out without a CSRF header while the page has a `<meta name="csrf-token">` (or `name="csrf"`). | Apps that post without the driver setting above. | Add the driver setting; the warning is gone in production builds.                                          |
| `HttpError` has a new variant, `HttpTimeoutError` (from `makeHttpDriver({ timeoutMs })`).                                                              | Exhaustive `switch`es over `HttpError._tag`.     | Add a `case 'HttpTimeoutError'`.                                                                           |

## Exports removed from the public API (all packages)

Every export was reviewed before 0.3.1 locks the API (gyral-1zd.6); the full list, entry point
by entry point, is [public-api-0.3.1.md](public-api-0.3.1.md). None of these were documented
for apps.

| Change                                                                                                                                                                                                                                                                                                | Who is affected                                                               | Fix                                                                                                                                                                       |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `StoreRegistry` and `withStoreScope` are exported from `@gyral/core/server` only.                                                                                                                                                                                                                     | Custom server renderers importing them from `@gyral/core`.                    | Import them from `@gyral/core/server`.                                                                                                                                    |
| `headEntries`, `HEAD_ATTRIBUTE`, `HeadEntry`, `scriptSafeJson`, `STORE_SEND`, `StoreSendInput`, `STORE_SEED_ATTRIBUTE`, `warnJsonHazard`, `formFields`, `formDataToObject`, `intentRejectedSchema`, `runInit`, `ISLAND_ATTRIBUTE`, `devtoolsEnabled` and `devtoolsLiveComponents` left `@gyral/core`. | Code that imported these internals.                                           | Use the documented APIs (`Head` with `page()`/`setHead()`, `form()`, `submitForm()`, `step()`). `@gyral/core/internal` has them for Gyral's own packages, with no semver. |
| `isLightComponent` and `findInScope` are no longer exported.                                                                                                                                                                                                                                          | Code that imported them.                                                      | Check `LIGHT_ATTRIBUTE` on the host; query your own root.                                                                                                                 |
| `@gyral/core/vite` exports only `gyralVitePreset`, `gyralTemplateCompiler`, `gyralClientOnly` and their option types.                                                                                                                                                                                 | Vite configs that composed the inner plugins or read the condition constants. | Use `gyralVitePreset()`; it sets up the dev server, source locations and resolve conditions.                                                                              |
| `@gyral/core/eslint` exports only the plugin (and `GyralPlugin`).                                                                                                                                                                                                                                     | Configs that imported `templateRule`, `rowPurityRule` or `unusedIntentRule`.  | `gyral.rules['template']` (and so on), or `gyral.configs.recommended`.                                                                                                    |
| `capturedUrl` (`@gyral/router`), `customElementsIn` and `undefinedElementsIn` (`@gyral/testing`), `makeTime`, `TimeOptions` (`@gyral/time`) and `makeDelayTime` (`@gyral/time/delay`) are no longer exported.                                                                                         | Code that imported them.                                                      | `hydrated()` reports undefined elements; commands always use the `time` driver, substituted by name.                                                                      |
| `@gyral/devtools` exports only `mountDevtools` and its types; `@gyral/mcp` only `createServer`, `loadCorpus`, `refreshDocs` and the corpus types; `create-gyral` only `parse`, `scaffold`, `manifest` and their types.                                                                                | Code that reused the panel model, the MCP tool functions or the CLI helpers.  | Use the remaining API; the MCP tools and the CLI behave as before.                                                                                                        |

# Behavior changes in 0.3.1

Gyral 0.3.1 is a patch release, but it changes some 0.3.0 behavior and types. This is a
one-time exception before 1.0's strict versioning: these changes fix defaults that were wrong
or close gaps that 0.3.0 left open, and each has a one-line fix. Testers on a 0.3.1-next.N build
should read this list too, because some items changed between those builds.

The package changelogs summarize the final release surface; the tables below collect the
behavior changes and their migration steps.

## Router (`@gyral/router`)

`href()` now rejects unknown route names, missing required parameters, empty/dot-segment
values and invalid catch-all arrays. Supply every required string and catch-all array
(use `[]` for an empty catch-all), and use literal separators where optional omissions
would make the generated URL capture different params. Optional `:id?` and trailing
`:path*` routes are supported in 0.3.1; see ADR 0009.

| Change                                                                                                                                                                                                | Who is affected                                                                          | Fix                                                                                                                             |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `routes()` throws at startup for patterns the two matchers would read differently: `:post-id`, `/v:id`, empty or dot segments, a param named twice, `#`.                                              | Route tables with such patterns.                                                         | Rename params to identifiers (`/:postId`) and drop the odd segments.                                                            |
| Empty segments never match: `/users//1` no longer matches `/users/:id`.                                                                                                                               | Apps that relied on the fallback matcher's leniency.                                     | Redirect to `match(url).path` (ADR 0009 "Canonical paths").                                                                     |
| `RouteMatch` has a required `path` (the canonical URL).                                                                                                                                               | Tests comparing a whole match with `toEqual`; code building matches by hand.             | Add `path`, or compare `name` and `params`.                                                                                     |
| `href()` writes non-ASCII literal segments percent-encoded (`/café` → `/caf%C3%A9`).                                                                                                                  | Snapshot tests of generated links.                                                       | Update the snapshots.                                                                                                           |
| After a push, the browser router scrolls to the `#fragment` target or the top, restores the position on back/forward, and resets focus.                                                               | Apps that manage scroll or focus themselves.                                             | `navigate(url, { scroll: false, focusReset: false })` per call, or `makeRouter({ scroll: false, focusReset: false })`.          |
| A `replace` leaves scroll and focus alone unless asked.                                                                                                                                               | Apps that expected a replace to scroll to the top.                                       | `navigate(url, { replace: true, scroll: true, focusReset: true })`.                                                             |
| Without the Navigation API, the History API path loads on first use, so the first navigation resolves a moment later. If it can't load, navigations become full page loads.                           | Tests that assume a synchronous first navigation in browsers without the Navigation API. | Await `settled()` (or the router's `Routed` message) after navigating.                                                          |
| `setTitle(title)` is removed; `setHead(head)` states the page's whole managed head (ADR 0019). The router input `{ _tag: 'Title' }` is `{ _tag: 'Head', head }` and `RouterSnapshot.title` is `head`. | Apps that call `setTitle`; custom router fakes; tests reading `snapshot().title`.        | `setHead({ title })`, or `setHead(pageHead(…))` with the same function the server passes to `page()`; `snapshot().head?.title`. |

## Retries and HTTP (`@gyral/core`, `@gyral/http`, `@gyral/testing`)

Retries and CSRF tokens are reached by calling them, so apps that don't use them don't bundle
them ([ADR 0022](../design-docs/0022-http-opt-outs.md)). Every item below is a type error, so
the type checker finds each site.

| Change                                                                                                                                                 | Who is affected                                  | Fix                                                                                                        |
| ------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| `Driver.retry` and `subscription(…, { retry })` are removed; the runtime runs a driver once.                                                           | Drivers and subscriptions with a `retry` policy. | Wrap the driver: `retry(driver, { times, delayMs, backoff })` from `@gyral/core`.                          |
| `makeHttpDriver({ retry })` is removed.                                                                                                                | Apps that gave the http driver a retry policy.   | `retry(makeHttpDriver({ … }), policy)`.                                                                    |
| `HttpRequest.csrf` (`request({ csrf: { meta } })`) is removed.                                                                                         | Requests that read a CSRF token from a `<meta>`. | Configure it once: `makeHttpDriver({ headers: csrfFromMeta('csrf-token') })`, given with `provideDrivers`. |
| `submitForm(url, data, { csrf: { meta } })` is removed; `{ csrf: { token } }` stays.                                                                   | Forms that read a CSRF token from a `<meta>`.    | The same driver setting.                                                                                   |
| The `retry` option of `fakeDriver` (`@gyral/testing`) and `fakeHttp` (`@gyral/http/testing`) is removed.                                               | Tests of retry behavior.                         | `retry(fakeDriver(…), policy)`; keep reading `calls` and `inputs` from the fake itself.                    |
| Development builds warn once when a non-GET request goes out without a CSRF header while the page has a `<meta name="csrf-token">` (or `name="csrf"`). | Apps that post without the driver setting above. | Add the driver setting; the warning is gone in production builds.                                          |
| `HttpError` has a new variant, `HttpTimeoutError` (from `makeHttpDriver({ timeoutMs })`).                                                              | Exhaustive `switch`es over `HttpError._tag`.     | Add a `case 'HttpTimeoutError'`.                                                                           |

## Errors (`@gyral/core`, `@gyral/ssr`, `@gyral/testing`)

Every failure Gyral catches now goes through one channel ([ADR 0024](../design-docs/0024-errors.md)):
a `GyralError` (`component`, `phase`, `msg`, `cause`), a bubbling `ErrorEvent('error')` on the
failing host that a parent can claim, the component's `spec.error` view or `Errored` reducer,
then `reportError` unless claimed.

| Change                                                                                                                                                                                                             | Who is affected                                                                                | Fix                                                                                       |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Failures that were only logged (a view, an async parser, a command mapper, post-render work, a deferred output: G0012, G0030–G0032, G0040) are reported with `reportError`, so `window`'s `error` event sees them. | Browser tests that make a component fail on purpose: Vitest fails the run on a reported error. | Wrap them in `collectErrors()` from `@gyral/testing` and assert on `collected.errors`.    |
| A driver failure with no `onFailure` is reported as an error (G0041), not a `console.warn`.                                                                                                                        | Commands whose failures were ignored.                                                          | Add `onFailure`, or an `Errored` reducer.                                                 |
| A throwing `init`, synchronous parser or reducer for an intent no longer escapes `connectedCallback` or the event listener; it is reported with context.                                                           | Code that relied on the exception escaping (a `try` around `append()`).                        | Listen on `window` `error`, or catch it in a parent boundary (`data-intent-on="error"`).  |
| `el.send(msg)` reports a reducer failure instead of throwing.                                                                                                                                                      | Code that wrapped `send()` in `try`.                                                           | An `Errored` reducer, or a `window` `error` listener.                                     |
| A reducer that throws for a command result is reported as an update failure (G0073), not as "command mapper threw" (G0040).                                                                                        | Code matching G0040 for reducer failures.                                                      | Match G0073.                                                                              |
| A store reducer that throws is reported (G0076) and doesn't throw to the sender; a store subscriber that throws (G0077) no longer keeps the other subscribers stale or the store's commands from running.          | Code that caught a store's failure at `send()`.                                                | Listen on `window` `error`.                                                               |
| An element hook that throws no longer skips the other hooks of the render (G0075).                                                                                                                                 | Apps that hit the old behavior.                                                                | Nothing to do.                                                                            |
| A failed `PropsChanged` reducer gets `PropsChanged` again with the next render.                                                                                                                                    | Reducers that throw on some props.                                                             | Make the reducer total, or reduce `Errored`.                                              |
| `Errored` is a framework message name (like `PropsChanged`); a message of your own named `Errored` now also receives Gyral's.                                                                                      | Message unions with an `Errored` variant.                                                      | Rename your variant.                                                                      |
| On the server, a component that throws renders its `error` view (or nothing), marked `data-gyral-error` without a seed, and the page goes on; `renderPage` no longer sends a truncated body.                       | Apps that expected the stream to fail.                                                         | `renderPage({ onError: 'throw' })` to fail before any byte is sent; `onError: fn` to log. |
| G0031, G0040 and G0041 have new texts; G0073–G0078 are new.                                                                                                                                                        | Code matching those messages.                                                                  | See [errors](errors.md).                                                                  |
| `DevEvent` has a new `kind: 'error'`.                                                                                                                                                                              | Exhaustive switches over `DevEvent` (custom devtools panels).                                  | Add a case.                                                                               |

## The essential surface (all packages)

A second pass (gyral-1zd.24, owner decisions O6, O8, O9 and R2 to R6 of the 0.3.1 surface
assessment) removed what apps rarely used or could write in a few lines, and folded duplicates.
Every removal is a type error at the import, so `tsc` finds each site.

| Change                                                                                                                                                                                                                                                               | Who is affected                                              | Fix                                                                                                                                                                                                              |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `defineDisposableHook` and `DisposableHookSpec` are removed: `defineHook` takes an optional `dispose(el, args)`.                                                                                                                                                     | Hooks with a teardown                                        | `defineHook({ client, dispose })`; nothing else changes.                                                                                                                                                         |
